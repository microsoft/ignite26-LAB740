# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB740: CXO Workshop Build Your AI Chief of Staff: Your First Digital Employee
### Session description

Build an AI strategic partner in Microsoft 365 Copilot that reflects your goals, values, and working style. Create a Human Persona from available work context, configure your agent's instructions and knowledge, and use conversation starters to turn strategy into action.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Complete [Exercise 00: Welcome to your lab environment](instructions/Exercise00.md) to sign in to the virtual machine and choose your workshop account.
2. Open [Microsoft 365 Copilot](https://m365.cloud.microsoft/chat) using your selected workshop account.
3. Follow [Exercise 01: Build your strategic partner agent in Microsoft 365 Copilot](instructions/README.md#exercise-01-build-your-strategic-partner-agent).

#### On your own

If you're learning at your own pace:

1. Open [Microsoft 365 Copilot](https://m365.cloud.microsoft/chat).
2. Sign in with your own Microsoft 365 work account that has access to Copilot and Agent Builder.
3. Follow [Exercise 01: Build your strategic partner agent in Microsoft 365 Copilot](instructions/README.md#exercise-01-build-your-strategic-partner-agent).

Website maintainers can find local preview and build instructions in the [website guide](docs/README.md).

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Create a Microsoft 365 Agent leveraging a Human Persona grounded in work context
- Configure agent instructions and knowledge sources to align responses with your goals, values, and working style.
- Test and coach your agent to support recurring tasks

### 💻 Technologies used

- Microsoft 365 Copilot
- Agent Builder
- Work IQ
